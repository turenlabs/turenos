Project picker — options

Submenu

Smallest change: keep one menu, push the project list sideways.

  1. Main menu stays short. "Projects ▸" plus the selected project's actions — never more than ~8 rows no matter how many projects exist.
  2. The list slides out to the side on hover — same items as today (All projects, unseen badges, check, Add project), one extra hover away.
  3. Everything already exists. MenuV2 wraps Kobalte, which supports Sub/SubTrigger/SubContent — no new UI surface to build.

Trade-offs

  • Switching projects is hover → click instead of one click.
  • Submenus are fiddly near window edges; panel is left-anchored so there's room.

Split menu

Two gestures, two single-purpose menus.

  1. Click the chip → picker only. All projects + the list + Add project. Nothing else — the menu does one job.
  2. Right-click the chip → project actions. New session / Edit / Reveal / Clear / Close for whichever project is selected, in a compact context menu.
  3. Each menu stays scannable because navigation and actions never share a panel.

Trade-offs

  • Actions live behind right-click — poor discoverability for trackpad/touch users unless we also add a visible affordance.
  • The picker is still one long flat list; fine at 11 projects, less fine at 30.

Header selector

The project filter moves onto the "Sessions" title row — it reads as a property of the list below it.

  1. "spice ▾" sits on the section header next to a "⋯" for actions. The chip row keeps only status filters (All / Running / Archived) and never overflows.
  2. The picker drops from the header — same list, same check/badges — while "⋯" owns the actions menu.
  3. Clear hierarchy: header = scope of the list, chips = lenses over it.

Trade-offs

  • Two controls on the header row to learn (selector vs ⋯).
  • Long project names truncate against the "SESSIONS" label — needs a max-width.

Popover picker

The picker stops pretending to be a menu — it becomes a small panel with room to breathe.

  1. Click the chip → a real panel: filter field, full-height project list with avatars + unseen badges + check, Add project pinned at the bottom.
  2. Actions live on the selected row's "⋯" — hover reveals it, click opens the actions menu right where the project is.
  3. Scales: search + taller list makes 30 projects as easy as 5.

Trade-offs

  • Most to build — it's a custom popover, not a stock dropdown menu.
  • Search is overkill at 3 projects; the field can auto-hide under N items.
